# Product research: lessons from Obsidian

Research consulted on October 26, 2026 for the first Fablethread release.

## Recurring praise

- Local, portable files give writers control over their work.
- Backlinks and a graph help reveal relationships between ideas.
- Flexible notes can serve different writing methods.
- Offline access and Markdown improve long-term portability.
- Novelists find linked notes particularly useful for characters and worldbuilding.

## Recurring criticism

- A blank starting point and many configuration choices create a steep learning curve.
- Plugin setup can become a project of its own.
- Long-form book workflows often need several separate plugins.
- A global graph can look appealing without showing a useful next action.
- Connected notes do not automatically become a finished manuscript.
- Paid official sync and mobile friction are common complaints.

## Fablethread's response

| Finding | Product choice |
| --- | --- |
| Writers value ownership | Local saving and Markdown export without an account |
| Connections are useful | A story map for characters, places, themes, objects, and events |
| Setup can distract | A complete book workflow on first launch |
| New users want direction | A sample book, chapter stages, and scene prompts |
| Notes do not always become prose | Manuscript and outline live in the same project |
| Graphs need purpose | Editable story elements with explicit connections and notes |
